## Bookmarks — `bookmarks.md`

Saved web links with context for later reference and querying.

**Format:**
```markdown
## Category Name

### [Page Title](https://url)
- Added: YYYY-MM-DD
- Tags: tag1, tag2
- Description: What the page is about and why it was saved.
```

**Querying:** Read `bookmarks.md` directly. Filter by category section, tags, or keyword in title/description.

**Adding a bookmark:** Append the entry under the matching category section. Create the section if it doesn't exist yet. Always fill in all four fields (Added, Tags, Description).

**When to read:** Only when the user asks about a saved link, wants to find a bookmark by topic, or asks to add/update/delete a bookmark. Do not load during daily briefings or task/event flows.
